## Background

Jack liked the branding work so much he asked me to design his website as well. The main job was to give LumberJack Tree Services one central hub for everything: the YouTube channel, the Instagram, the reviews, the phone number.

I went dark with the interface on purpose. Against near-black, the brand's oranges and greens do all the work.

![](/images/work/pixel-jam/lumberjack-tree-services-website-design/01.webp)

## The work

I designed every breakpoint properly rather than letting the desktop layout squash itself down. Desktop, tablet and mobile each got their own pass, so the site holds together whatever it's viewed on.

## The result

Launch was smooth. The site runs on WordPress, so Jack can edit the whole thing himself, and I wired in an Instagram gallery, a YouTube video roll and a Checkatrade review widget so it stays fresh without him touching it.

With tidy code and properly processed images, it passed its performance benchmarks with room to spare.
