# Case study imagery — shot list

Every suggestion below also sits as a `<!-- image suggestion -->` comment inside its
markdown file at the exact spot the image should go. Comments don't render on the site,
so nothing looks broken in the meantime. Drop new files into
`public/images/work/<slug>/`, then replace the comment with `![](/images/work/<slug>/<file>)`.

General principles across the set:
- **Show motion as motion.** Anywhere an interaction is described (3D models, drag-and-drop,
  animated logo), a short looping MP4/GIF will outsell any still.
- **Process shots build trust.** Sketches, rejected routes, wireframe-to-final pairs —
  clients hire the thinking, not the final JPEG.
- **Real beats rendered.** Photos of printed pouches, actual vehicle livery, a uniform —
  use them wherever they exist.
